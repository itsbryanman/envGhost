# Security policy

Report vulnerabilities privately to security@env-ghost.invalid (placeholder,
to be replaced before the first release). Please don't open public issues
for them.

Include the env-ghost version or commit, kernel version, output of
`env-ghost doctor`, and steps to reproduce.

Known limits are listed in [docs/threat-model.md](docs/threat-model.md) and
measured in [docs/harness-results.md](docs/harness-results.md). A new way
around env-ghost that isn't on those pages is worth reporting, as is any
case where env-ghost claims more than it does.
